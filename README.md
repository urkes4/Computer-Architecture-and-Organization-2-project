## KVM Hypervisor

Developed a C/C++ hypervisor using the Linux Kernel-based Virtual Machine (KVM) API. Implemented support for 64-bit virtual machines, configurable guest memory and page sizes, multiple VMs running concurrently using POSIX threads, and I/O communication through virtual ports.

Extended the hypervisor with file operations, shared files with copy-on-write support, and inter-VM communication through interrupts and a shared buffer.

**Technologies:** C, C++, KVM API, Linux, POSIX Threads, Virtualization, Interrupts, File I/O
